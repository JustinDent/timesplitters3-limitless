# Security policy

## Report privately

If you find a vulnerability that could expose private information, run
untrusted code or compromise a player's computer, **do not post exploit
details in a public issue or Discussion**.

Open the repository's [Security advisories page](https://github.com/TheDoffman/timesplitters-future-perfect-pc/security/advisories)
and choose **Report a vulnerability** to send a private report through GitHub.
Sign in to GitHub if needed. This reaches the repository maintainers without
publishing the report.

Include what you know:

- The affected game and/or launcher version, and your operating system.
- What can go wrong, who is affected and steps to reproduce it.
- A small, safe example or relevant logs with personal information removed.

Reports may involve the launcher, updates, file importing, runtime or online
features. Test only on systems and files you own or have permission to test.
Do not include game files, personal saves, passwords, tokens or other people's
private information.

## Versions and follow-up

Security work focuses on the latest published game and launcher releases,
including prereleases. Older versions have no guaranteed backported fixes;
please say if you can also reproduce the problem on the latest release.

We will assess the report and coordinate any fix and public disclosure through
the private report. Response and fix times depend on maintainer availability
and the issue; there is no guaranteed deadline or paid bug bounty.

Ordinary crashes, visual problems and feature requests belong in the
[issue forms](https://github.com/TheDoffman/timesplitters-future-perfect-pc/issues/new/choose).
For community conduct concerns, see [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
