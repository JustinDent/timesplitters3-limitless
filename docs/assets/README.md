# README visuals

- `launcher-preview.png`: UI preview rendered by the published Windows launcher
  v1.1.2 using its `--render-preview` command. It shows illustrative installed
  version/channel values, not the current latest game release or a gameplay test.
  The README caption makes that distinction and directs players to Preview.
- Rendered application SHA-256:
  `294d4896299f9d2b26a080553d2646c940a62d68f7401c7270237fa8a650de8b`.
  This matches the v1.1.2 launcher package manifest. Rendering opens no game,
  performs no update and includes no personal settings, paths or saves.
- `download-launcher.svg`: small self-contained download button matching the
  launcher's silver/blue palette. Its link and accessible label are in the README.

The PNG documents the released interface, including its embedded branding.
Raw source artwork and original game assets remain private. Keep one launcher
preview here and replace it when the documented interface changes.
