## Activation

The installed supervisor reads the public guides fresh at task startup and
local continuations, selects at most two topic excerpts plus the map (6.5 KB
maximum), and includes selected reference material inside the existing total
20-KB Sol handoff. Local complexity/progress reviewers also receive that map.
Unchanged guide excerpts are not repeated on every local continuation; a changed
selection/content or native compaction restores them. Two lifecycle regressions
verify deduplication, compaction recovery and initial preflight delivery.
Ordinary hosted sessions keep their normal behavior and use root AGENTS links.

An already-running supervisor keeps loaded JavaScript modules until restart.
Reload the LOCAL SMART window before its next task; if the backend persists,
fully close LOCAL SMART windows and reopen through the usual Start shortcut.
Audits for new supervised tasks contain `repositoryContext.status`, `files` and
`bytes`, so actual delivery can be checked without inferring it from the UI.
After rebasing, the installed reader loaded the updated #105 guide selection
at 4,725 bytes and the actual VS Code setting still referenced the existing

advisory acceptance above used the earlier guide wording; the delivered facts

Guides live on the focused Git branch. Another branch/device needs the context
commit through normal Git integration; the machine router does not invent a
guide snapshot when a checkout lacks it. The index covers Git-indexed patches;
untracked experiments are clearly labelled by the finder and are not certified.
